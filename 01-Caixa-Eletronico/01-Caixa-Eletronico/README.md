# Caixa Eletrônico

Sistema simples de caixa eletrônico desenvolvido em Python.

## Objetivo

Primeiro projeto desenvolvido para praticar lógica de programação utilizando Python e criar uma aplicação simples executada pelo terminal.

## Funcionalidades

* Consulta de saldo
* Depósito
* Saque
* Validação de valores inválidos
* Controle de opções do menu
* Confirmação para saída do sistema

## Conceitos praticados

* Variáveis
* Estruturas condicionais (`if/elif/else`)
* Laços de repetição (`while`)
* Entrada de dados com `input()`
* Conversão de tipos
* Validação de informações

## Funcionamento

O usuário interage com um menu no terminal, podendo consultar o saldo, realizar depósitos e saques. O sistema realiza validações para evitar operações inválidas.

## Tecnologias utilizadas

* Python
* Git
* GitHub
