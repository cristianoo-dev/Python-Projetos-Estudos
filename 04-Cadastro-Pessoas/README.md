# Cadastro de Pessoas

Sistema de cadastro de pessoas desenvolvido em Python.

## Objetivo

Projeto criado para praticar manipulação de dados utilizando listas e dicionários, além de aplicar validações e tratamento de erros em uma aplicação executada pelo terminal.

## Funcionalidades

* Cadastro de pessoas
* Armazenamento de informações como nome, idade e cidade
* Listagem de pessoas cadastradas
* Busca de pessoas pelo nome
* Edição de informações cadastradas
* Remoção de registros
* Validação de entradas
* Tratamento de opções inválidas

## Conceitos praticados

* Listas
* Dicionários
* Funções
* Manipulação de dados
* Validação de entradas
* Tratamento de exceções (`try/except`)
* Controle de fluxo
* Organização de código

## Funcionamento

O sistema permite cadastrar, consultar, editar e remover pessoas através de um menu interativo. Os dados são armazenados em estruturas de dados durante a execução do programa.

## Tecnologias utilizadas

* Python
* Git
* GitHub
