# GameTracker

Sistema de gerenciamento de jogos desenvolvido em Python.

## Objetivo

Projeto criado para praticar organização de código utilizando funções, manipulação de listas e dicionários, além da criação de um sistema completo de gerenciamento de informações.

## Funcionalidades

* Cadastro de jogos
* Listagem de jogos cadastrados
* Busca de jogos pelo nome
* Alteração do status dos jogos
* Remoção de jogos com confirmação
* Validação de entradas do usuário
* Tratamento de opções inválidas
* Busca sem diferenciar letras maiúsculas e minúsculas utilizando `casefold()`

## Conceitos praticados

* Criação e utilização de funções
* Parâmetros e retorno de funções
* Listas e dicionários
* Manipulação de dados
* Estrutura de menus
* Validação de informações
* Reutilização de código
* Organização de funcionalidades

## Funcionamento

O usuário interage com um menu no terminal onde pode cadastrar e gerenciar jogos. Cada operação foi organizada em funções separadas, facilitando a manutenção e reutilização do código.

## Tecnologias utilizadas
