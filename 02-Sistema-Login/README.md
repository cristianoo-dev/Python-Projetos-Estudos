# Sistema de Login

Sistema de autenticação desenvolvido em Python.

## Objetivo

Projeto criado para praticar estruturas de decisão, validação de dados e controle de fluxo através da criação de um sistema simples de login.

## Funcionalidades

* Cadastro de usuário e senha definidos no código
* Validação de usuário e senha
* Controle de tentativas de acesso
* Bloqueio após múltiplas tentativas inválidas
* Tratamento de campos vazios
* Mensagens de retorno para diferentes situações

## Conceitos praticados

* Estruturas condicionais (`if/elif/else`)
* Laços de repetição (`while`)
* Variáveis
* Operadores lógicos
* Validação de entradas
* Controle de fluxo do programa

## Funcionamento

O usuário informa suas credenciais para acessar o sistema. O programa compara os dados informados com os dados cadastrados e controla a quantidade de tentativas permitidas antes de bloquear o acesso.

## Tecnologias utilizadas

* Python
* Git
* GitHub
