# Lista de Tarefas

Sistema simples de gerenciamento de tarefas desenvolvido em Python.

## Objetivo

Projeto criado para praticar manipulação de listas, controle de fluxo e organização de funcionalidades através de um sistema interativo executado pelo terminal.

## Funcionalidades

* Adição de tarefas
* Listagem de tarefas cadastradas
* Controle de tarefas utilizando lista
* Tratamento de lista vazia
* Validação de entradas do usuário
* Confirmação para saída do sistema

## Conceitos praticados

* Listas
* Manipulação de dados
* Estruturas condicionais (`if/elif/else`)
* Laços de repetição (`while` e `for`)
* Entrada de dados com `input()`
* Organização de menus no terminal

## Funcionamento

O usuário interage com um menu no terminal onde pode cadastrar e visualizar tarefas. As informações são armazenadas temporariamente durante a execução do programa utilizando listas.
